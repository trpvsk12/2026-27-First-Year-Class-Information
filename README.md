# First Year Class Information - Installable App

This is a Progressive Web App (PWA).

## Files
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

## Upload to GitHub
Upload all files and folders to the ROOT of your GitHub repository.

## Enable GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save

## Install
After the GitHub Pages website opens:
- Android Chrome: Menu → Install app / Add to Home screen
- Desktop Chrome/Edge: Click the Install icon in the address bar

The app can also work offline after it has been opened once.
