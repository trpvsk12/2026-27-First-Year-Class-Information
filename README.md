# First Year Class Information App

A simple GitHub Pages web application to view:

- Class Incharge
- Phone Number
- Classroom
- Block
- Floor
- Search facility

## GitHub Pages Deployment

1. Create a new repository on GitHub.
2. Upload all files in this folder:
   - index.html
   - style.css
   - app.js
3. Open **Settings** → **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Click **Save**.
7. GitHub will provide your website link.
